# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `warrenboswell/laravel-ai-guardrails` (such as a prompt boundary bypass or numerical parsing edge case), please do **not** open a public GitHub issue.

Instead, please report it privately via email to **[warren@boswell.dev](mailto:warren@boswell.dev)** with:

1. A description of the vulnerability and its potential impact.
2. Minimal PHP reproduction code demonstrating the issue.

All security reports are reviewed promptly and acknowledged within 48 hours.
